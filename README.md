# Kubernetes MCP Demo 项目

本项目演示如何通过MCP (Model Context Protocol) 服务在Kubernetes集群中执行Python代码，特别适用于数据分析、批处理任务和机器学习推理场景。

## 项目特性

- 🚀 **自动化作业管理**：基于Kubernetes Job的代码执行
- 📊 **数据分析支持**：内置CSV数据分析模板
- 🔄 **动态配置**：根据用户需求自动调整作业参数
- 🧹 **自动清理**：作业完成后自动清理资源
- 📝 **结果监控**：实时监控执行状态并获取结果

## 项目结构

```
mcp-demo/
├── default-prompt.md          # 默认提示词模板（核心配置）
├── csv-analysis-job.yaml      # CSV数据分析作业模板
├── .claude/
│   └── project-settings.json  # 项目配置文件
└── README.md                  # 项目说明文档
```

## 核心组件

### 1. 默认提示词模板 (`default-prompt.md`)
包含完整的Python代码执行指导流程，涵盖：
- 作业配置适配规则
- MCP工具调用序列
- 常见使用模式
- 资源配置建议
- 错误处理策略

### 2. CSV分析作业模板 (`csv-analysis-job.yaml`)
参考模板，包含：
- ConfigMap：存储Python代码和运行脚本
- Job定义：完整的Kubernetes作业配置
- 数据处理：从RustFS下载CSV并进行分析
- 结果输出：生成JSON和文本格式报告

### 3. 项目配置 (`.claude/project-settings.json`)
- 自动加载默认提示词
- MCP服务器配置
- 默认环境参数

## 执行流程

1. **需求识别**：分析用户问题，确定需要Python代码执行
2. **配置生成**：基于模板动态生成Kubernetes作业配置
3. **作业提交**：使用MCP工具提交到集群
4. **状态监控**：实时监控作业执行状态
5. **结果获取**：获取执行结果并进行处理
6. **资源清理**：自动清理完成的作业资源

**详细的MCP工具使用说明请参考 `CLAUDE.md` 文件**

## 配置说明

### 必需环境变量
- `TASK_ID`：任务唯一标识符
- `PYTHONUNBUFFERED`：设置为"1"

### 可选环境变量
- `RUSTFS_ENDPOINT`：S3兼容存储端点
- `BUCKET_NAME`：数据桶名称
- `FILE_NAME`：目标文件名

### 资源配置
支持三种预设配置：
- 轻量级任务：CPU 200m/1000m，内存 256Mi/512Mi
- 中等任务：CPU 500m/2000m，内存 512Mi/2Gi
- 重型任务：CPU 1000m/4000m，内存 1Gi/4Gi

## 输出规范

所有作业输出统一保存在 `/output/` 目录：

- `result.json`：JSON格式结构化结果
- `analysis_report.txt`：文本格式可读报告
- `stdout_stderr.log`：执行日志
- `exit_code.txt`：退出状态码

## 安全最佳实践

1. **敏感信息管理**：避免在配置中硬编码密钥
2. **资源限制**：设置合理的CPU和内存上限
3. **网络隔离**：在适当的命名空间中运行
4. **自动清理**：使用TTL机制自动清理资源

## 故障排查

### 常见问题
1. **作业启动失败**：检查镜像拉取权限和资源配额
2. **数据访问错误**：验证存储端点和认证信息
3. **执行超时**：调整`activeDeadlineSeconds`参数
4. **内存不足**：增加内存限制或优化代码

### 日志查看
详细的日志查看方法请参考 `CLAUDE.md` 文件中的故障排除部分。
