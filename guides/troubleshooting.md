## 🔧 MCP工具故障

### 🚨 MCP服务不可用 - 立即停止处理

#### 触发条件
- `claude mcp list` 显示服务连接失败（✗ Failed to connect）
- **工具级别错误**：
  - MCP工具调用返回 "No such tool available" 错误
  - 权限配置错误导致的工具调用失败
  - 工具名称不匹配或工具未正确注册
- **可以重试的情况**（这些不应该触发立即停止）：
  - 网络临时问题/超时
  - 服务暂时不可用
  - 内部错误但服务本身正常

#### 🛑 立即响应流程（优先级最高）
**绝对禁止**：
- ❌ 禁止尝试本地Python分析
- ❌ 禁止创建临时文件
- ❌ 禁止绕过MCP服务进行其他操作
- ❌ 禁止继续执行工作流后续步骤
- ❌ **禁止尝试诊断或修复MCP服务**（这不是AI助理的工作）
- ❌ **禁止遇到K8s不可重试问题时寻找替代方案**（直接报错停止）

**必须执行**：
1. **立即停止所有处理流程**
2. **直接向用户显示标准化错误信息**
3. **不尝试任何形式的自检或修复**

**标准化错误提示模板**：

**连接失败模板**：
```
❌ MCP服务当前不可用

系统检测到MCP服务连接失败，无法处理您的请求。

🔧 建议解决方案：
1. 检查MCP服务是否正常运行
2. 联系系统管理员重启MCP服务
3. 稍后重试

📋 服务状态：
- mcp-k8s: 连接失败
- mcp-rustfs: 连接失败

请等待MCP服务恢复后重新提交您的分析请求。
```

**工具级别错误模板**：
```
❌ MCP工具配置错误

系统检测到MCP工具本身配置存在问题，无法正常调用。

🔧 错误类型：
- 工具未正确注册或权限配置错误
- 工具名称不匹配
- MCP服务配置问题

📋 建议解决方案：
1. 检查.claude/settings.local.json中的工具权限配置
2. 确认MCP服务配置是否正确
3. 联系系统管理员检查工具注册状态

请等待MCP工具配置修复后重新提交您的分析请求。
```

#### 恢复后处理
- MCP服务恢复后，用户需要重新提交原始请求
- 重新开始完整的工作流程
- 不保存任何中间状态或临时文件

### mcp-rustfs 故障

#### 症状：工具调用失败或返回错误
**注意**：只有在MCP服务可用时才执行以下诊断

**诊断命令**：
```bash
# 检查服务器连接
mcp__mcp-k8s__server_status

# 列出可用bucket
mcp__mcp-rustfs__list_buckets
```

**常见问题与解决**：

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 连接超时 | 网络不通 | 检查RustFS服务状态 |
| 权限拒绝 | 认证失败 | 检查环境变量配置 |
| 文件不存在 | 路径错误 | 验证bucket和文件名 |
| 编码错误 | 文件格式问题 | 尝试不同编码方式 |

#### 文件访问故障排除
```bash
# 1. 检查bucket是否存在
mcp__mcp-rustfs__list_buckets

# 2. 检查文件是否存在
mcp__mcp-rustfs__check_file_exists file_path="demo.csv" bucket="tmp"

# 3. 检查CSV文件结构
mcp__mcp-rustfs__get_csv_columns file_path="demo.csv" bucket="tmp"

# 4. 列出CSV文件
mcp__mcp-rustfs__list_csv_files bucket="tmp"
```

### mcp-k8s 故障

#### 🚨 K8s不可重试问题 - 立即报错停止

**触发条件**（遇到以下情况立即停止，不尝试替代方案）：
- **网络插件错误**：Calico/Flannel等CNI插件权限或配置问题
- **RBAC权限问题**：ServiceAccount缺少必要权限
- **集群组件故障**：API Server、etcd、scheduler等核心组件异常
- **存储类问题**：PVC/PV相关配置错误
- **镜像仓库问题**：无法访问指定镜像仓库

**立即停止流程**：
1. **识别错误类型** → 判断是否为不可重试的系统性问题
2. **记录错误信息** → 保存详细的错误日志和状态信息
3. **显示标准化错误** → 向用户报告问题并建议联系管理员
4. **停止所有处理** → 不尝试任何形式的替代方案或本地处理

**标准化错误提示模板**：
```
❌ Kubernetes集群存在不可重试的系统问题

检测到以下系统级错误，无法继续执行分析任务：

🔧 错误详情：
- 错误类型：[网络插件权限问题/RBAC配置错误/集群组件故障等]
- 具体错误：[详细错误信息]
- 影响范围：任务无法在Kubernetes中正常执行

📋 建议解决方案：
1. 联系系统管理员检查Kubernetes集群状态
2. 修复网络插件权限或RBAC配置
3. 确保集群核心组件正常运行
4. 验证镜像仓库访问权限

请等待集群问题解决后重新提交分析请求。
```

#### 其他可重试问题诊断

**诊断命令**：
```bash
# 检查集群节点状态
mcp__mcp-k8s__get_nodes

# 检查Pod状态
mcp__mcp-k8s__get_pods namespace="default"

# 检查服务状态
mcp__mcp-k8s__get_services namespace="default"
```

**可重试问题与解决**：

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 镜像拉取失败 | 镜像地址错误 | 使用指定镜像：registry.opsman.top/kmai/python:3.12-alpine-data |
| 资源不足 | 集群资源临时耗尽 | 调整资源限制或等待资源释放 |
| 临时网络问题 | 网络波动 | 重试任务执行 |
| Pod调度延迟 | 调度器临时繁忙 | 等待或稍后重试 |

## 🚀 任务执行故障

### Job启动失败

#### 症状：Pod处于Pending或Failed状态
**诊断流程**：
```bash
# 1. 获取Pod状态
mcp__mcp-k8s__get_pods namespace="default"

# 2. 查看Pod详情
mcp__mcp-k8s__kubectl command="describe pod {pod-name} -n default"

# 3. 查看Pod日志
mcp__mcp-k8s__kubectl command="logs {pod-name} -n default"
```

#### 常见Pod状态分析

| 状态 | 含义 | 解决方案 |
|------|------|----------|
| Pending | 资源调度中 | 等待或增加资源 |
| ImagePullBackOff | 镜像拉取失败 | 检查镜像地址 |
| CrashLoopBackOff | 容器启动失败 | 检查脚本语法 |
| OOMKilled | 内存不足 | 增加内存限制 |
| Error | 执行错误 | 查看具体错误信息 |

### 任务执行超时

#### 症状：任务运行时间超过预期
**解决方案**：
```bash
# 1. 检查任务资源使用
mcp__mcp-k8s__kubectl command="top pods -n default"

# 2. 增加超时时间
# 修改YAML中的 activeDeadlineSeconds

# 3. 优化分析脚本
# 减少数据量或优化算法
```

## 📊 数据分析特定故障

### CSV文件读取失败

#### 常见编码问题
```python
# 在分析脚本中使用多重编码尝试
try:
    df = pd.read_csv('/data/demo.csv', encoding='utf-8')
except UnicodeDecodeError:
    try:
        df = pd.read_csv('/data/demo.csv', encoding='gbk')
    except:
        df = pd.read_csv('/data/demo.csv', encoding='latin-1')
```

#### 文件格式问题
| 问题 | 症状 | 解决方案 |
|------|------|----------|
| 分隔符错误 | 列数不匹配 | 尝试不同分隔符：, ; \t |
| 表头问题 | 列名错误 | 跳过表头或手动指定 |
| 数据类型错误 | 转换失败 | 强制类型转换 |

### 内存不足错误

#### 症状：OOMKilled或MemoryError
**解决方案**：
```bash
# 1. 增加内存限制
resources:
  limits:
    memory: "1Gi"

# 2. 分块读取大文件
df = pd.read_csv('/data/large.csv', chunksize=10000)

# 3. 优化数据处理
# 只保留需要的列，使用合适的数据类型
```
